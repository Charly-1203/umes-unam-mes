# Registros de decisiones de arquitectura (ADR)

Cada ADR documenta una decisión que afecta la estructura del proyecto: el contexto, la decisión y
sus consecuencias. Permiten entender, tiempo después, por qué el sistema es como es.

## Cómo agregar uno

1. Copia [plantilla.md](plantilla.md) como `NNNN-titulo-corto.md` con el siguiente número.
2. Llénalo y agrégalo a la tabla de abajo en el mismo pull request.
3. Un ADR aceptado no se edita: si la decisión cambia, se crea uno nuevo que lo reemplace.
