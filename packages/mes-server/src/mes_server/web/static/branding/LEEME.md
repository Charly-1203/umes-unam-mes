# Escudos institucionales

Coloca aquí los archivos oficiales para que aparezcan en la aplicación:

| Archivo | Dónde aparece |
|---|---|
| `escudo-unam.svg` | Menú lateral y pantalla de inicio de sesión |
| `escudo-dependencia.svg` | Pantalla de inicio de sesión, junto al nombre de la Universidad |

Se aceptan `.svg` (recomendado), `.png` o `.webp`. Mientras no existan, la aplicación muestra
un ícono genérico en su lugar.

Usa siempre las versiones oficiales, sin deformarlas, y respeta el área de protección y el tamaño
mínimo que indica el manual de identidad gráfica de la dependencia. Para fondos azules usa la
versión del escudo para fondo oscuro.
